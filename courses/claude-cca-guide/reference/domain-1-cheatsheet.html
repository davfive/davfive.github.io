1.2 — Coordinator-subagent hub-and-spoke

  • All communication routes through the coordinator; subagents never talk directly to each other.
  • Subagents have isolated context — findings must be placed directly in the subagent's prompt.
  • Coordinator's jobs: decomposition → delegation (minimize overlap) → aggregation (iterative refinement).
Signature trapOverly narrow decomposition — every subagent executes correctly, but the coordinator never assigned a whole category of the topic.

1.3 — Subagent invocation, context passing, spawning

  • Task tool spawns subagents; coordinator's allowedTools must include "Task".
  • Multiple Task calls in one response = parallel execution. One-per-turn = sequential.
  • Write goals and quality bars into subagent prompts, not rigid step-by-step scripts.

1.4 — Multi-step workflows: enforcement & handoff

  • Programmatic enforcement (hooks, gates) = deterministic. Prompt instructions = probabilistic, never zero-failure.
  • Multi-concern requests: decompose → investigate in parallel → synthesize one resolution.
  • Human handoffs need a structured summary (ID, root cause, amounts, recommended action).

1.5 — Agent SDK hooks

  • PostToolUse hook normalizes inconsistent tool result formats before the model sees them.
  • Hooks can block an outgoing tool call outright when it violates a business rule.

1.6 — Task decomposition strategies

  • Prompt chaining (fixed sequence) for predictable shape; dynamic decomposition for open-ended investigation.
  • Attention dilution fix: per-file local passes + separate cross-file integration pass.

1.7 — Session state, resumption, forking

  • --resume continues a named session; fork_session branches from a shared baseline.
  • Staleness trap: inform a resumed session about specific changed files rather than assuming context is current.
Cross-cutting rulestop_reason is the only reliable loop signal. Isolation and deterministic enforcement are the two recurring fixes across this whole domain.

Glossary (Domain 1)

Hub-and-spoke: coordinator routes all inter-agent communication.
Isolated context: a subagent's default — no memory of the coordinator's history unless given explicitly.
Narrow decomposition: a task breakdown that omits whole categories, not just under-executes one.
Deterministic enforcement: a hook or programmatic gate that makes a skip physically impossible, vs. prompt guidance which only makes it unlikely.

Path-Specific Rules for Conditional Convention Loading

Some conventions don't map to a directory — they map to a file pattern. Rules with glob scoping handle that case.

The mechanism

.claude/rules/ files can carry YAML frontmatter with a paths field containing glob patterns — e.g. paths: ["terraform/**/*"]. The rule only loads into context when Claude is actually editing a matching file, keeping irrelevant conventions (and their token cost) out of sessions that don't touch that area.

Why glob beats directory-level CLAUDE.md here Some conventions span files scattered across the whole codebase — test files, for instance, live throughout the tree, not in one subdirectory. A glob like **/*.test.tsx catches every one of them regardless of location; a directory-level CLAUDE.md structurally can't.

Rule of thumb: reach for path-specific rules when the convention is defined by file type, and directory-level CLAUDE.md when the convention is defined by file location.

Check your understanding

Scenario
Your team has strict conventions for all *.test.tsx files — consistent mocking patterns, no snapshot tests, required cleanup in afterEach — but these test files are scattered across dozens of unrelated directories throughout the codebase. What's the most effective way to enforce this?
ACreate a .claude/rules/ file with paths: ["**/*.test.tsx"] so it loads for any matching file regardless of location.
BWrite a directory-level CLAUDE.md in each directory that happens to contain test files.
CAdd the testing conventions to the root-level project CLAUDE.md so every session loads them.
DCreate a custom slash command that developers run manually before writing any test file.
Correct This is exactly the guide's stated advantage of path-specific rules: a glob pattern like **/*.test.tsx applies by file type wherever the file lives, which directory-scoped CLAUDE.md structurally cannot do without duplicating the file in every directory.
Not quite Directory-level CLAUDE.md files would need to be duplicated across every directory containing a test file — brittle and easy to miss one. Loading the conventions into the root CLAUDE.md means every session pays the token cost even when no test files are being touched. A manual slash command depends on the developer remembering to invoke it, defeating the point of automatic conditional loading.
